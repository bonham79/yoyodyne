# Maori passives (`mri`)

Author(s): Selin Alkan, Kyle Gorman

Source(s): Biggs 2009, Ryan 1989, Te Aka

## Summary

This data consists of Maori verbs and their corresponding passive versions. While the most common passive suffix is _-tia_, there are many other variants observed in the data set. There are also some verbs that exhibit stem change in the passive; others undergo reduplication.
